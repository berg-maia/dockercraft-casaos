# dockercraft-casaos

An unofficial [CasaOS](https://casaos.zimaspace.com/) app store for the **Craft** applications: open-source, clean-room reimplementations of well-known creative and office applications, rebuilt in pure Rust and served in your browser.

> **Application credits:**
> - **ArtCraft applications:** Developed by the [ArtCraft Team](https://getartcraft.com) and their respective contributors.
> - **SolidCraft:** Developed by [Tangency Labs](https://solidcraft.io) and its contributors.
>
> This repository only packages their work for CasaOS. It is not an official ArtCraft or Tangency Labs repository.

## Install

1. Open the CasaOS dashboard and go to **App Store**.
2. Click **Add Source** and paste:

   ```
   https://github.com/berg-maia/dockercraft-casaos/archive/refs/heads/main.zip
   ```

3. Pick an app from the new source and install it. Open it at `http://<your-server-ip>:<port>` using the port from the table bellow.

Each app uses its own host port, so all of them can run side by side.

> **Note:** If newly added applications do not appear in the CasaOS App Store, even after removing and re-adding the repository, try restarting the CasaOS App Management service.
>
> **Via SSH:**
> Connect to your CasaOS device via SSH and run:
   ```
   sudo systemctl restart casaos-app-management
   ```
